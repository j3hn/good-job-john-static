Catch the thought before it disappears

Flair is an Android voice-to-Markdown app, developed in the VoiceNote project. The focus is a small, direct capture loop: record, pause when needed, save and return to what you were doing.

Keep the capture close

The implementation uses Kotlin and Jetpack Compose, with whisper.cpp for on-device transcription. Notes are stored as Markdown, with configurable front matter, categories and an optional folder mirror.

A deliberately small interface

The current build includes recording, a waveform, transcription and a saved-note list. The design question is how much organisation to offer without getting in the way of capturing an idea. The illustration here explores that direction; it is not a screenshot of the Android build.

In development · The visual is a portfolio interface study. Features described reflect project documentation, rather than a released product.
